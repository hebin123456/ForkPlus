第 26 章 · 对比视图插件机制

ForkPlus 用户手册 · 版本 v5.0.1

总览 AI 对话框与工具 对比视图插件

从 v5.0.0 起，ForkPlus 把「对比视图」重构为插件化架构：原先写死在主程序里的图片对比与 Hex 对比拆分为两个独立的插件 DLL，由主程序在启动时从 plugins/ 目录动态加载。这样一来，不重新编译主程序即可增删对比视图插件，第三方也能以插件形式为新的文件类型提供专属对比视图。v5.0.1 起，偏好设置新增「插件」管理页——可查看插件名称、版本号与描述，启用/禁用插件，并重新加载插件（无需重启）。本章说明插件如何认领文件、如何路由、如何在偏好设置里管理，以及内置插件的行为。

为什么插件化

  • 可扩展：为新的文件类型（如某种领域格式）提供专属对比视图时，只需新写一个插件 DLL，无需改动主程序。
  • 可替换 / 可覆盖：任何内置对比视图都能被更高优先级的插件或用户绑定覆盖。
  • 按需加载：主程序启动时扫描 plugins/，一个 DLL 一个插件，随读随用。
  • 行为不变：内置插件的对比行为与 v4.3.2 保持一致——图片走图片对比器，其余二进制走 Hex 对比器。

内置插件

ForkPlus 自带两个内置对比视图插件，覆盖了绝大多数场景：

插件 ID名称 / 版本认领范围说明
forkplus.image 图片对比
1.0.0		 精确扩展名：.bmp .gif .png .jpg .jpeg .ico .tga .webp 图片对比插件：并排 / 滑动 / 洋葱皮 / Hex 四种模式，含动图播放、像素差异高亮、缩放平移与 LFS smudge；优先级 100。
forkplus.hex 十六进制对比
1.0.0		 通配兜底：任何未被专属插件认领的文件类型 Hex 对比插件：默认 side-by-side 文件卡片（图标 + 扩展名 + 大小 + LFS 徽章）；宿主预载字节（≤50MB）时可切换到 Hex 对比。

图片对比插件（forkplus.image）

图片对比插件提供第 7 章介绍的四种对比模式，为图片与动图提供图形化差异视图。

Hex 对比插件（forkplus.hex）

Hex 对比插件是所有二进制的兜底视图。未加载该 DLL 时，ForkPlus 同样会显示文件卡片视图。

插件路由规则

一个文件该交给哪个插件渲染，由 DiffViewPluginRegistry 按下面的优先级决定：

  1. 用户绑定：用户显式把某个扩展名绑定到指定插件（BindExtension）时优先采用。
  2. 精确扩展名：插件声明的扩展名表命中时采用（如 .png → 图片对比插件）。
  3. 通配兜底：以上都不命中时，交给声明为通配兜底的 Hex 对比插件。
说明：第三方插件只要声明更高的优先级，或通过用户绑定，即可覆盖内置插件的行为。

插件契约与宿主桥接

插件通过独立的契约工程 ForkPlus.Plugins.Abstractions 与主程序对接，其中定义了 IDiffViewPlugin、IDiffView、IDiffViewHost、DiffViewContext 等类型。插件本身不感知 Git 领域类型与主工程；一切宿主能力都经 PluginEnvironment / IDiffViewHost 桥接注入，包括：

  • 本地化：按当前界面语言取文案；
  • 设置：读取用户偏好；
  • 剪贴板：复制内容；
  • LFS smudge：还原 LFS 指针为真实内容；
  • 保存对话框：导出视图内容；
  • 文件图标：按扩展名取图标。

内置的图片插件与 Hex 插件共用一层共享组件（ForkPlus.Plugins.Ui）：文件卡片面板（BinaryContentPanel）、回退面板（DiffFallbackPanel）、Hex 编辑内核（HexDiffUserControl / HexEditor）、动图播放组件等不再复制两份代码，而是由两个插件共同引用。

插件管理器（偏好设置 → 插件）

从 v5.0.1 起，可在「偏好设置 → 插件」页集中管理对比视图插件，无需手工改文件、也无需重启：

  • 查看插件信息：每个插件展示名称、版本号、描述，以及它认领的匹配扩展名与优先级；加载失败的 DLL 会单独列出并标明失败原因，不影响其他插件。
  • 启用 / 禁用：用每行的开关即时启用或禁用插件。禁用只把插件排除出对比路由，插件条目与元数据仍保留，可随时重新启用；禁用状态会持久化，下次启动沿用。
  • 重新加载插件：点击「重新加载插件」按钮，ForkPlus 会重建插件注册表并重新扫描 plugins/ 目录——放入或删除插件 DLL 后立即生效，无需重启；用户绑定与禁用状态跨重载保持。
  • 打开插件目录：点击「打开插件目录」直接定位到 plugins/，方便投放或替换插件 DLL。
说明：插件的名称、版本号与描述由插件自身通过 IPluginMetadata 契约提供；未实现该接口的插件会回退显示为「显示名 + 程序集版本 + 空描述」，不会因此无法加载。

安装第三方插件

  1. 把插件 DLL 放入程序的 plugins/ 目录（一个 DLL 对应一个插件；也可在偏好设置 → 插件页点「打开插件目录」定位）。
  2. 在「偏好设置 → 插件」页点击「重新加载插件」即可立即加载，无需重启 ForkPlus（DiffViewPluginLoader 会重扫描该目录）。
  3. 如插件声明的扩展名与内置插件冲突，可让插件声明更高优先级，或把扩展名绑定到该插件来指定使用。
小贴士：开发插件时以 ForkPlus.Plugins.Abstractions 为唯一依赖，不要直接引用主工程——所有需要的能力都从 IDiffViewHost 获取，这样插件才能独立分发、独立升级。

与旧版行为的一致性

插件化属于内部架构重构，默认对比行为与 v4.3.2 完全一致：

  • 图片文件 → 图片对比插件（四模式、动图播放、缩放平移、LFS smudge）；
  • 其余二进制 → Hex 对比插件（文件卡片，预载字节时可切 Hex 对比）；
  • 不加载 Hex 插件 DLL 时，同样显示文件卡片视图作为回退。

关于各模式的详细操作，请参见 第 7 章 · 二进制与图片 Diff。
