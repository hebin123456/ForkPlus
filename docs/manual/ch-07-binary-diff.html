对于图片与其他二进制文件，ForkPlus 不再以文本行对比，而是提供专用的图形化差异工具，帮助你直观判断一张图、一个二进制文件在两个版本间到底改了什么。选择图片文件时提供四种对比模式；非图片二进制则提供简略卡片与 Hex 视图。

图片 Diff：四种对比模式

选中一个发生变更的图片文件后，编辑器下方出现四个模式按钮：并排 / 滑动（Swipe）/ 洋葱皮（Onion Skin）/ 十六进制（Hex），并标注「旧」「新」两个版本。

并排（Side-by-Side）

默认模式：并排显示旧图（左侧）与新图（右侧），一目了然看到两版的全貌差异。

滑动（Swipe）

滑动模式在两张图上叠加一条可拖动的分隔线：左侧露出旧图、右侧露出新图。左右拖拽分隔线即可在任意位置「刮开」对比新旧内容，非常适合精确定位某个像素区域的改动。

洋葱皮（Onion Skin）

洋葱皮模式把旧图叠在新图上，通过透明度滑杆控制底层（新图）的显露程度，模拟「洋葱皮透叠」效果。完全不透明时只见顶层旧图。

十六进制（Hex）

十六进制模式用双 Hex 编辑器展示图片文件的原始字节（左右分栏、逐字节对齐），供需要从二进制层面审查图片数据的场景使用。

放大查看：滚轮缩放与拖动平移

图片较小、细节看不清时，不必再截图放大——上述并排 / 滑动 / 洋葱皮三种模式都可以直接在图片区域用鼠标滚轮放大缩小。放大到超出可视区域后，按住左键拖动即可平移查看（光标变为四向移动样式），平移被限制在图片边界内，不会拖出空白留白；未放大到超出可视区域时拖动不生效。

并排左右两栏、以及切换模式后的各视图共用同一套缩放与位置：一处缩放，各视图同步；一处拖动，两栏同步平移。两张图片尺寸不一致时按中心点对齐——同一图像位置始终位于左右对应的屏幕位置上，方便逐像素比对。

只要缩放比例不再是 100%，图片区域中间偏下就会悬浮出现「还原大小 (N%)」按钮（与解决冲突页的合并按钮一样居中悬浮，而不是挤在底部的视图模式按钮里），N 为当前缩放百分比；点击即回到贴合视图的 100% 初始状态（并排、滑动、洋葱皮同步还原）。切到「十六进制」时该按钮隐藏——那种模式不参与图片缩放。

动图直接播放：GIF / 动态 WebP / APNG

对比的两张图若是动图（GIF / 动态 WebP / APNG），ForkPlus 不再只显示第一帧，而是直接按帧自动播放，无需逐帧对比。每列图片区域底部居中悬浮一条播放控制条，包含：

  • 播放 / 暂停：打开动图后默认自动播放，点按钮可暂停或继续；
  • 上一帧 / 下一帧：逐帧步进查看（步进时会暂停播放）；
  • 播放速度：0.5× / 1× / 2× 三档；
  • 帧序号：如 1/2，实时显示当前帧与总帧数。

动图会自动关闭像素差异高亮（逐帧的像素差异没有意义）；切换到「滑动 / 洋葱皮 / 十六进制」或切换文件时，播放会暂停并释放帧内存，回到并排视图再继续。为控制内存占用，帧数或总像素超过阈值的超大动图会退回只显示第一帧。

非图片二进制的简略卡片视图

对于非图片的二进制文件（如 .bin），ForkPlus 提供简略卡片视图：左右两个卡片分别显示「旧」「新」版本的文件图标与字节大小（如 256 B → 512 B），不尝试解析内容，仅直观告知文件变化与体积变化。此时模式按钮只保留 并排 / 十六进制 两项（滑动 / 洋葱皮自动隐藏）。

Hex 视图

点击「十六进制」把二进制文件切到 Hex 视图，以字节（十六进制）形式逐行对比新旧内容，左右双编辑器对齐，可精确查看每个字节的变化。

大文件 Diff

对于体积较大的二进制文件，Hex 视图首屏只渲染开头一段字节，并提供「加载更多」分页加载机制，按需读取后续内容，避免一次载入大文件造成卡顿。

小贴士：处理图片改动时，先用「并排」看整体、再用「滑动」或「洋葱皮」定位具体差异区域；细节看不清就直接滚轮放大 + 拖动平移（左右同步、中心点对齐），看完点「还原大小」回到全貌；若怀疑文件结构异常，切到「十六进制」核实原始字节。
