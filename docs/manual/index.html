ForkPlus 用户手册

跨平台 Git 客户端 · Windows / Linux / macOS · 版本 v5.0.2

总览

欢迎

本手册介绍 ForkPlus 的安装、界面与全部功能模块。各章节由自动化场景实测截图编写。

v5.0.2 更新

  • 新手引导新增「对比视图插件」步骤：向导在「随心定制」与「结束」之间新增一步，介绍对比视图插件化（图片/Hex 对比为独立插件 DLL，启动时从 plugins/ 动态加载）、偏好设置 → 插件页的查看/启禁用/重新加载，以及到插件发布页下载更多插件；步骤总数 12 → 13，文案随 8 种界面语言发布。详见第 1 章 · 欢迎页与仓库管理。
  • 偏好设置 → 插件页新增插件下载超链接：在「重新加载插件」「打开插件目录」旁新增超链接，直达 ForkPlus-Plugins 的 Releases 页面，一键获取最新插件。详见第 26 章 · 对比视图插件机制。

v5.0.1 更新

  • 插件管理器：偏好设置新增「插件」页，集中展示每个对比视图插件的名称、版本号、描述、匹配扩展名与优先级，可即时启用/禁用（禁用仅退出路由、状态持久化）并重新加载插件——放入或删除插件 DLL 后无需重启 ForkPlus 即可生效。内置图片对比与 Hex 对比插件版本号定为 1.0.0 并补充中文名称/描述（元数据国际化留待后续版本）。详见第 26 章 · 对比视图插件机制。
  • 文档补齐：偏好设置「插件」标签页标题已随界面语言本地化（8 种语言）；第 21 章 · 偏好设置新增「各标签页一览」，为全部设置标签页逐页配图。

v5.0.0 更新

  • 对比视图插件化：图片对比与 Hex 对比从主程序拆分为独立的插件 DLL，由主程序启动时从 plugins/ 目录动态加载——不重新编译主程序即可增删对比视图插件。内置图片对比插件（forkplus.image）与 Hex 对比兜底插件（forkplus.hex），对比行为与 v4.3.2 保持一致。文件按「用户绑定 > 精确扩展名 > 通配兜底」路由到插件，第三方插件以更高优先级或用户绑定即可覆盖内置插件。详见第 26 章 · 对比视图插件机制。

v4.3.2 更新

  • 图片对比动图播放：图片 Diff 的并排视图支持直接播放动图（GIF / 动态 WebP / APNG），不再只显示第一帧。每列图片区域底部居中悬浮播放控制条：播放/暂停、上一帧/下一帧、播放速度（0.5×/1×/2×）与帧序号；动图自动关闭像素差异高亮，切视图/换文件自动暂停并释放帧内存，超大动图退回首帧。详见第 7 章 · 二进制与图片 Diff。

v4.3.1 更新

  • 图片对比放大查看：图片 Diff 的并排 / 滑动 / 洋葱皮三种模式支持在图片区域滚轮缩放，放大超出可视区域后可按住拖动平移；并排两栏与各模式之间共享同一缩放与中心点，尺寸不同的两张图按中心点对齐同步平移。只要缩放不为 100%，对比视图中间偏下就会悬浮出现「还原大小 (N%)」按钮（与解决冲突页合并按钮一样居中悬浮），一键回到贴合视图的初始状态（各视图同步还原；切到十六进制时隐藏）。详见第 7 章 · 二进制与图片 Diff。

v4.3.0 更新

  • 新手引导（Getting Started）：首次启动自动弹出 12 步分步向导，先过一遍核心界面（工具栏 / 分支侧栏 / 提交历史与 Diff / 提交变更），再介绍进阶能力（git mm 工作流 / 仓库树图 / 仓库统计 / Reflog 时间轴 / 解决冲突 / 主题与语言定制），每步配示意图。走完或跳过都算已完成并写入设置，之后不再自动弹出；菜单栏「帮助 › 新手引导」可随时重看（重看不会重置完成标记）。全部文案随 8 种界面语言发布。详见第 1 章 · 欢迎页与仓库管理。
  • 体验修复：删除远端弹窗（Remove Remote）此前 logo 图标与文字、内容与命令预览相互重叠，已按通用弹窗布局规范重排（图标列 + 标题行 + 内容行），并移除一个与基类成员重名的死控件。详见第 13 章 · 远程交互。

v4.2.1 更新

  • 仓库健康检查窗口：新增「仓库健康检查」独立窗口，分区折叠展示仓库体检结果——概览（对象体积 / 关注项）、陈旧分支、已合并分支、分叉分支（未推送 / 分支独有提交）、最大的文件与 .git 体积明细；陈旧 / 已合并分支可勾选批量删除，删除前二次确认，受保护分支会被拦截。详见第 20 章 · 查看器窗口。
  • 提交预览区重做：Pull / Push / Reset 三处共用的「将包含的提交」预览区，折叠头与摘要行左对齐、SHA 与提交说明同行对齐，列表限高滚动不再把窗口撑高；预览行的短 SHA 变为超链接，点击即可打开该提交的变更详情。详见第 13 章 · 远程交互与第 11 章 · 历史改写。
  • 丢弃更改确认窗口：丢弃更改（含子模块）由消息框升级为专用确认窗口，按「子模块 / 文件」分组列出将丢弃的路径，长列表可滚动、超大列表截断提示（…and N more）。详见第 5 章 · 变更与提交。
  • 重开已关闭标签页：新增 Ctrl+Shift+T，按最近关闭顺序重开仓库标签（栈空或路径已失效时静默跳过）；原「新建标签」快捷键改为 Ctrl+Shift+G。详见第 8 章 · 键盘快捷键。
  • 体验修复：Reflog 窗口表头随列表行几何实时对齐（滚动条出现 / 消失不再错位）；从非模态 Reflog 窗口弹出的确认框正确归属该窗口，关闭后不再把 Reflog 窗口压到主窗口下面。

v4.2.0 更新

  • 标签条布局：主窗口仓库标签条支持顶部 / 左侧 / 右侧三种布局；左侧/右侧为 VSCode 风格垂直标签条，可拖拽调宽（120–600px）、可一键收拢，布局与宽度自动记忆。详见第 2 章 · 主界面总览。
  • 分支下拉框搜索：推送 / 拉取 / 跟踪远程 / Worktree / GitFlow 等窗口的分支下拉框内新增搜索框，可即时过滤分支，分支较多时无需逐个翻找。详见第 13 章 · 远程交互。
  • 体验修复：修订详情文本可拖选复制、下拉过滤消除残影、搜索框焦点更稳定、主菜单弹层定位修正。
